## 关于我段落：星海列车改造

用户要求把「Up in the Cloud Sea」的美术风格改成「星海列车」并融进个人网站「关于我」这一段：
符合站点主题色、星光闪烁、滚动时星海与列车逐层浮现、卡片缩小并从天上落下、卡片中文化且做成云朵形，
并强调「尽可能保留参考的美术效果」。

做法与决策：
- 找到参考原作（TAMU / Tianxiu Zhou，改编自 mdb 的 ShaderToy Ndc3zl）的 GLSL 源码，
  **保留** 11 层 fbm 云带、矢量火车/桥/车轮/烟、前景运动模糊、暗角；只把暖色按亮度映射到
  深蓝—钢蓝—霜白（nightGrade），新增 starLayer/skyColor、车窗灯、uReveal 分层浮现。
  这样比自己重画更贴近「保留美术效果」。
- 蓝噪声纹理：TAMU 直链下载被截断（Content-Length 4,202,841，只拿到 1,639,894，无 IEND），
  浏览器报 `texImage2D: bad image data`，云海退化成平滑带子。改从 GitHub blob API 取完整 PNG，
  用 PIL 抽出 R 通道存成 1024×1024 R8 `blue-noise.bin`（1 MB），JS 用 `texImage2D(..., Uint8Array)`
  上传，彻底绕开浏览器解码。以后遇到外部大图资源务必校验 IEND/长度。
- 停用（未删除）`light-rays.js` 初始化，`.profile-light` 降级为 CSS 冷光晕；`profile-section.js`
  新增本段滚动进度 → `setReveal()` / `setActive()`。
- 改动文件：`star-sea.js`(新)、`assets/star-sea/`(新)、`index.html`、`profile-section.css`、
  `profile-section.js`、`server.cjs`（白名单 + `.bin` MIME）、`README.md`、`NOTICE.txt`。
- 验证：无头 Edge(``--use-angle=swiftshader``) + CDP 脚本截图，确认纹理上传成功、无 WebGL 错误、
  中间态只有部分云带且火车未出现、滚到底全浮现、1440×900 中文可读。

用户补充：站点**已经部署在公网上**，README 里「未部署」的旧描述已修正；本地改动需重新发布才生效。
